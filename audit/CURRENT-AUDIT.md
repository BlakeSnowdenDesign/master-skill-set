This audit supersedes earlier access and publication-status statements in the historical draft documents. Those documents describe the earlier evidence review, not this collection.

- **Snowden-Design** — default branch plus every branch advertised by the remote during collection, including separate contact, about, packages, brushed-menu, SEO/GEO, website-hub and architectural-3D implementations.

The studio entry is now a thin router into the shared library; existing repository history is preserved.

The exact refs, revisions, file hashes and exclusions are recorded in [current-source-manifest.json](current-source-manifest.json). Identical files shared by branches are stored once, with every collected branch reference retained in the manifest.

- **LimeTreeSocial** — public inventory entry exists, but its remote returned no refs. Lime Tree Hospitality case-study code was collected from Home Refresh instead and remains separately identified.
- Public account listing returned five repositories in one page. It is not a private-repository account-wide inventory. Home Refresh access was established separately through the configured Git remote.

## Collection boundaries

This is a code-and-technique compendium, not a byte-for-byte backup of every repository. It excludes agent memories, private profiles, environment files, dependency directories, binary media and text exports larger than 5 MB. Asset paths and URLs remain in the collected source. Large generated outputs should be rebuilt from their original project.

The collector rejects common credential patterns before inclusion, but this is not a comprehensive security scan. Source collection and checksum validation do not establish runtime correctness, licensing clearance, technical accuracy of construction claims, or successful publication in Wix.

The user's instruction authorizes publishing this compendium to the existing master-skill-set repository. Original project repositories are not rewritten or force-pushed.

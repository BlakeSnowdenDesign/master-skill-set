# Optional agent-instruction adapters

These are **copy-ready suggestions**, not installed instruction files. Placement/discovery differs by assistant/version; confirm current documented support first. Do not override existing project instructions or create these remotely as part of this draft.

For an environment supporting `AGENTS.md`, `CLAUDE.md`, or a manually pasted session instruction, use the same small pointer:

```text
For relevant web-development work, read the owner-provided master skillet/README.md
and its audit/COVERAGE.md first. Confirm the target project, select its profile,
then load only relevant skills and references. The draft is workspace-only and
does not establish current upstream approval. Report missing access and conflicts.
Do not transfer one project's branding or asset rights to another.
No remote writes or publication are authorized by the package.
If the package is unavailable, request the archive rather than guessing its URL.
```

Do not copy the entire package into every instruction file. Use [full prompt](../MASTER-PROMPT.md) for one-time loading, and keep the index available for progressive retrieval.

# Photography & Drone — separate Wix section

The section is in the Replit homepage preview after the MONGRAIN showcase.
It is also exported as its own `photography-drone.html` file.
It has not been added to the Wix editor or published.

1. Open `/review/photography` in the Replit preview and click **Copy section code**.
2. In Wix Studio Home, add a section after the 3D showcase.
3. Select **Add Elements → Embed & Social → Embed Code → Enter Code**.
4. Paste the section HTML and Apply. Stretch to the section width and remove
   unwanted outer padding.
5. Use the review screen's measured standalone heights as initial values.
   Check the actual Wix element width at every breakpoint, and adjust height
   to avoid clipping, nested scrollbars, and excess space.
6. Review in Wix Preview before publishing.

portfolio sample. No drone footage, certifications, licenses, client results,
or testimonials are invented. Contact links go to the existing Wix Contact
page, in the top frame.

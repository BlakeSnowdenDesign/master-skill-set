## 2. Page layout: native Wix vs the embed

Per the spec, text that should rank lives in native Wix elements. The embed is the visual and interactive layer. Stack the page like this:

1. **Native text, H1 + intro** (section 3). Set the heading to H1 in text settings.
2. **Embed HTML** `snowden-3d-visualization.html`, full width. Its own hero, live model, gallery and capability cards. Accessible name: "Interactive 3D building-envelope explorer for Mongrain". Enter it in the embed's Accessibility settings (Accessible name / title); Wix writes it to the iframe `title`. The embed's own hero headline is an H2, so the native H1 above it is the page's only H1.
3. **Native gallery** of the four renders with the alt text in section 4 (Pro Gallery or a grid of image elements). Images inside the embed don't count for image search; these do.
4. **Native text, case study paragraph and H2s** (section 3).
5. **Native text, FAQ** with each question as an H3 (section 3). Must match the schema word for word.
6. Site footer with the NAP block.

If you'd rather keep the page visually seamless, you can set the embed's own hero, gallery and FAQ to stay as they are and place the native blocks in a compact "About this project" strip under it. Either way the native text must be on the page.

**H2: 3D architectural visualization FAQ**

**What is 3D architectural visualization?** (H3)

3D architectural visualization turns drawings, CAD files or photos of a building into a 3D model people can see from any angle. Snowden Design builds them as interactive web scenes, so visitors can rotate a building, open its layers and understand how it goes together without reading a spec sheet.

**Can an interactive 3D model run on a Wix website?** (H3)

Yes. Snowden Design delivers each model as one self-contained HTML file that pastes into a Wix Embed HTML element. It needs no apps, plugins or Velo code, runs in any modern browser with WebGL, and falls back to still images and plain text when 3D or motion is turned off.

**What did Snowden Design build for Mongrain?** (H3)

For Mongrain, a building-envelope contractor, Snowden Design built an interactive 3D explorer of a hospital project. Visitors watch the building assemble from foundation to roof, click a wall, roof or foundation zone to explode its layers, and explore a 24-component BIM-style section and a six-section foundation systems page.

**What files do I need to start a 3D project?** (H3)

Whatever you already have is usually enough: CAD or BIM exports, architectural drawings, product spec sheets, PDFs or clear photos. Mongrain's models started from system drawings and photos of the finished building. Snowden Design simplifies that reference into a model that reads clearly on a phone or desktop screen.

**How much does 3D visualization cost?** (H3)

Every 3D project is quoted after a free consultation, because cost depends on how many assemblies the model shows, how much animation and interaction it needs, and where it will be published. Call 720-340-2611 or email blake@snowden-design.com with your drawings or photos for a fixed quote.

**Does interactive 3D content help SEO?** (H3)

It helps indirectly. A model keeps visitors engaged longer and earns links, but search engines and AI answer engines read text, not WebGL. That's why Snowden Design pairs every model with crawlable page copy, descriptive image alt text, FAQ content and schema markup, so the page around the model ranks and gets cited.

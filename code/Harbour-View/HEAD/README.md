# Harbour View Cottages

Wix Embed HTML pages and development skills for Harbour View Cottages, Harbour Island, Bahamas.

## Layout

| Path | What it is |
| --- | --- |
| `pages/rates/harbour-view-rates.html` | Rates & Availability page. Single self-contained file for a Wix Embed HTML element. Calendar availability is sample data. |
| `pages/homepage/` | Reserved for the six homepage sections (not yet in the repo, see below). |
| `content/` | Source copy: homepage copy (current and original) and the High Tide / Low Tide cottage descriptions. |
| `.claude/skills/wix-embed-page-build/` | Snowden Design house build skill: single-file Wix embeds, preview + copy code, motion and quality bar. |
| `.claude/skills/harbour-view-briland-luxury/` | Harbour View art direction ("modern Briland luxury") and client brand, used on top of the build skill. |

## Using a page in Wix

1. Add > Embed Code > Embed HTML.
2. Paste the full contents of the `.html` file.
3. Set the element to full width and set its height.

Photos and video are served from Wix (`wixstatic.com`); large source photos and films are not stored here.

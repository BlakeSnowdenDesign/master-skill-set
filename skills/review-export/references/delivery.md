# Delivery contract

Adapted from S14's review page and S12's exporter:

- Fetch visitor HTML from the configured artifact/base path, check HTTP success, and display errors.
- Disable copying until content is loaded.
- Catch clipboard failure and explain Download/manual-copy fallback.
- Offer a labeled preview iframe, read-only raw-code field, HTML download and setup notes.
- Do not copy the review page into the Wix embed.
- Exclude preview toolbar CSS and owner controls from generated visitor files.

Suggested handoff:

```text
Target and authorized scope:
Sources and revisions:
Chosen profile and modules:
Direct review page:
Visitor HTML/download:
Wix parent setup:
Checks actually performed:
Unavailable sources and untested behavior:
Owner approval/publication still needed:
```

This is a reusable workflow, not permission to publish or a claim the review route is private. Preserve project-specific routing and source attribution.

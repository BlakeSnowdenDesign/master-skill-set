# Accessibility and qualified SEO

**Evidence:** C05; S03/S05/S10, [manifest](../../audit/SOURCES.md).

1. Classify images: meaningful content describes useful context; image-only links describe action/destination; decorative images use `alt=""`. Do not duplicate a sufficient visible label or stuff keywords.
2. An iframe `title`, inner document `<title>`, image alt, and Wix page SEO title serve different purposes; configure separately.
3. Retain one clear visible native Wix H1, useful intro, real service details, project links and CTA. Metadata is not a substitute for visible text.
4. Set truthful unique titles/descriptions, intentional slugs/canonical and schema matching visible facts in the parent. Avoid invented prices, reviews, services or duplicate business definitions.
5. Distinguish Google iframe association from Wix internal Site Search. S05 qualifies Google's association as possible, not guaranteed; its 90% scenario is not a threshold. The cited Wix internal-search limitation is not proof Google cannot index frames.
6. If nearly all text must remain framed, prefer public crawlable semantic HTML at an independent URL; inspect both URLs in authorized Search Console. `srcdoc` alone does not provide that fallback. Do not blindly canonicalize the embed to its parent.
7. Verify current documentation when platform behavior matters; these sources are inherited guidance, not a new indexing audit. Separate training-crawler policy from search visibility; no blanket training opt-in.

Read [examples and sources](references/labels-and-search.md). Report screen-reader, Search Console and indexing checks only if actually performed.

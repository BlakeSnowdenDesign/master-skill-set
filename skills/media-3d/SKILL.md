# Media, lookbooks and 3D viewers

**Evidence:** C06/C07/C09; S08/S09/S12/S13/S14/S17/S18, [manifest](../../audit/SOURCES.md).

1. Retrieve the original viewer/presentation; do not reconstruct complex architectural assemblies or lookbook pages from screenshots. Keep wrapper notices and review tools separate.
2. For inline `srcdoc`, escape attribute content, supply a descriptive iframe title and test embedded routing separately from hosted routing. Keep adapters narrow, checked and confined to generated copies.
3. A rendered fallback proves fallback only. Test actual WebGL model/controls on a capable browser before claiming success; use approved poster/fallback instead of a blank area.
4. Use verified durable hosted media, posters, controls and inline playback. Delay heavy sources/presentations until needed. Respect reduced motion/data saving and manual pause. Handle playback rejection visibly.
5. Do not infer downloadable MP4 paths from HLS or retain expiring signed sources. Use approved hero imagery when no durable film exists.
6. Exact-source dashboard images are not chart-generation prompts. Retain figures, shapes, labels, map markers/colors and proportions; finite masks/glows only, ending unchanged. Disclose illustrative/demo/not-live status.
7. Access does not imply redistribution rights or public-client-data approval. This package contains no full viewer, original media or dashboard graphics.
